# AcpEditor

在 Unreal Engine 5 编辑器里直接跟 ACP agent 对话的面板：聊天、模型选择、权限确认、改动审阅，
不用切出编辑器。

## 组成

| 部分 | 位置 | 作用 |
|---|---|---|
| 编辑器插件 | 本目录 | 注册工具栏入口，内嵌浏览器面板 |
| 面板页面 | `Resources/web/index.html` | 聊天界面（与 `packages/web` 同源） |
| hub | 仓库根目录 `packages/hub` | 唯一与 agent 通信的进程：HTTP + SSE 对面板，ACP 对 agent |

面板本身不启动 agent。所有会话都由 hub 管理，插件只是它的一个客户端。

## 安装

1. 启动 hub（在仓库根目录）：

   ```bash
   pnpm install
   pnpm build
   pnpm start -- --cwd "D:/path/to/YourProject"
   ```

   默认监听 `http://127.0.0.1:7878`。

2. 把本目录复制到项目的插件目录：

   ```
   <YourProject>/Plugins/AcpEditor
   ```

3. 打开项目（或在编辑器里启用 **AcpEditor** 插件），重启编辑器。

4. 从工具栏打开 **ACP** 面板。

## 使用

- **Hub 地址**：面板顶部填写，默认 `http://127.0.0.1:7878`。hub 没启动时面板会提示连接失败。
- **Agent**：下拉列表来自 hub 的 `/agents`，显示每个 agent 解析到的路径、版本，以及缺失的能力。
- **会话**：新建、切换、从历史恢复。切换会话不影响其他会话。
- **模型 / 模式**：下拉项由 agent 自己通过 ACP 上报，hub 不写死。
- **权限**：工具调用会弹出确认（允许一次 / 总是允许 / 拒绝），默认模式是每次询问。
- **改动审阅**：agent 修改文件后，面板把改动显示为可对比的卡片，可逐条保留或还原。
- **编辑器上下文**：项目启用 `ModelContextProtocol` 插件后，会话会自动带上编辑器工具；agent
  也可以通过 `ue-mcp` 命令读取编辑器状态（打开的资产、选中项、内容浏览器路径、PIE、相机）。

## 注意事项

- 面板页面在标签页创建时加载一次。更新了面板资源后，用面板标题栏的 **×** 关掉再打开，或重启
  编辑器，才会用上新资源。
- hub 必须先运行；面板不会自动拉起它。
- 关闭面板标签会结束该标签自己的会话，其他会话不受影响。

## 环境

- Unreal Engine 5.8，Windows 10 及以上
- hub：Node.js 20.11+，pnpm 11
